An interactive 3D solar system simulation built with HTML, CSS, JavaScript, and Three.js. Explore a virtual solar system, interact with planets, and control the simulation through a simple user interface.

Features

  Interactive 3D Environment — Explore the solar system in a three-dimensional scene.
  
  Planet Inspection — Click on a planet to view information about the selected object.
  
  Pause and Resume — Control the simulation using the pause button.
  
  Reset Simulation — Reset the solar system using the reset control.
  
  Add Planets — Spawn additional planets using the add button.
  
  Camera Controls — Navigate the scene using mouse controls powered by Three.js OrbitControls.

Technologies Used:

  HTML5 — Application structure.
  
  CSS3 — Styling and user interface.
  
  JavaScript — Simulation logic and interactivity.
  
  Three.js — 3D rendering and visualization.
  
  OrbitControls — Interactive camera navigation.
